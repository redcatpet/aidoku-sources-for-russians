# Senkuro (ru.senkuro)

Источник для [Senkuro](https://senkuro.com): манга, манхва, маньхуа и комиксы на русском языке.

## Возможности

- Каталог, поиск и пагинация через `mangaTachiyomiSearch`.
- Домашняя страница с топом за день, неделю и месяц, последними обновлениями, новыми тайтлами и разделами по типам.
- Карточка, команды переводчиков, главы и страницы для чтения.
- Фильтры типа, формата, статусов, возрастного рейтинга и динамические группы меток из API.
- Прямые ссылки вида `/manga/<slug>` разрешаются в полный ID через поиск API.

Общий движок Senkuro и Senkognito находится в [`templates/senkuro`](../../templates/senkuro). Рабочий публичный API: `https://api.senkuro.com/graphql`.

## Настройки

- **Домен API** — публичный `api.senkuro.com` используется по умолчанию; региональный `api.senkuro.me` оставлен как дополнительный вариант. При его ошибке источник автоматически повторяет запрос через публичный API.
- **Английские заголовки** — использовать английские названия и подписи вместо русских, когда они доступны.

Senkuro скрывает взрослые метки и не добавляет их в динамические фильтры этого источника.
