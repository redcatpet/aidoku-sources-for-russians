# Senkognito (ru.senkognito)

Источник 18+ для [Senkognito](https://senkognito.com), работающий через общий GraphQL API Senkuro.

## Возможности

- Каталог и поиск требуют одновременно возрастной рейтинг `EXPLICIT` и метку `hentai`, поэтому обычные OEL и жёсткие, но не порнографические комиксы не попадают в выдачу.
- Домашняя страница содержит популярное, свежие главы, новые тайтлы и отдельные разделы манги, манхвы и маньхуа; общий раздел обычных комиксов скрыт.
- Сортировка и фильтры сайта: тип, формат, статусы, рейтинг, число глав, год, первоисточник и страна.
- Динамические фильтры используют актуальный справочник сайта, включая 42 действующие хентайные темы вместо сотен устаревших меток старого Tachiyomi API.
- Карточки, главы, страницы для чтения и прямые ссылки `/manga/<slug>`.

Общий движок находится в [`templates/senkuro`](../../templates/senkuro). Рабочий публичный API: `https://api.senkuro.com/graphql`.

## Настройки

- **Домен API** — `api.senkuro.me` предназначен для России, `api.senkuro.com` — для зарубежных сетей и VPN. При сетевой ошибке источник автоматически пробует второй API.
- **Английские заголовки** — использовать английские названия и подписи, когда они доступны.
